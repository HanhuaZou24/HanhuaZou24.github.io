01 About

I am studying computer science at the Academy of Artificial Intelligence and Advanced Technology, Xi’an Jiaotong-Liverpool University. My interests sit where operating systems, networks and data systems meet: how bytes actually leave one machine, what the kernel hides, and what the measurements really say.

Most of what I build starts as a question about a protocol. For CSI205TC Networking and Distributed Computing I implemented a video streaming system twice — once on TCP and once on UDP — and compared them frame by frame with Wireshark, which is where my interest in packet-level analysis comes from.

This page is a static site: hand-written HTML, CSS and JavaScript, no framework and no build step, served by GitHub Pages.

02 Selected projects

Four of the five coursework assignments, chosen because each one forced a different kind of engineering: transport design, distributed execution, and model evaluation.

TCP · UDP 01

Video streaming over sockets

A JPEG frame stream with two transports: a length-prefixed TCP byte stream and a fragmented UDP datagram channel with application-level reassembly. Both measure one-way latency per frame; a relay emulates loss and jitter so the failure modes are reproducible.

  • 0 % frame loss on both transports on a clean path
  • 27.5 % frame loss from 2 % datagram loss over an impaired path
  • Loss amplification follows (1 − p)n with n ≈ 17 fragments per frame

DNS · TLS · HTTP 02

Measuring this website

The site is its own experiment: every layer from the DNS lookup to the TLS handshake and the HTTP response is measured and captured, so the numbers in the report come from a real visit rather than from a diagram.

  • Domain name and the four GitHub Pages addresses it resolves to
  • TCP connect, TLS handshake and time-to-first-byte, measured
  • Wireshark capture of the DNS, TCP and TLS exchange
